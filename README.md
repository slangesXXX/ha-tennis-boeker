# Tennis Boeker – Home Assistant add-on

Boekt automatisch een tennisbaan bij een vereniging met een KNLTB.Club-website,
precies op het moment dat de baan opengaat.

## Installeren
1. Home Assistant → **Instellingen → Add-ons → Add-on Store**.
2. Rechtsboven **⋮ → Repositories**, voeg toe: `https://github.com/slangesXXX/ha-tennis-boeker`
3. Installeer **Tennis Boeker**, vul de **Configuratie** in en start de add-on.
4. Open **Tennisbaan** in de zijbalk.

Uitleg over de instellingen staat op het tabblad **Documentatie** van de add-on.

## Updates
Nieuwe versies verschijnen vanzelf als **Bijwerken** in Home Assistant.
Wat er per versie veranderd is, staat in [tennis_boeker/CHANGELOG.md](tennis_boeker/CHANGELOG.md).
